# Журнал решений
- Разбиение: train strat_fold 1-8, val 9, test 10.
- Версия данных: 100 Гц.
- Метки: учитываются все диагностические коды из scp_codes независимо от likelihood
  (min_likelihood: 0), как в бенчмарке PTB-XL. Записи без суперкласса исключаются.
- Нормализация: z-score по каждому из 12 отведений, mean/std только по train.
  В кэше лежат сырые сигналы, нормализация применяется при загрузке (src/data.py:load_splits).
- Test (фолд 10) не загружается по умолчанию: load_splits(splits=("train", "val")).
- Бейзлайн (src/features.py, src/baseline.py, configs/baseline.yaml): 12 статистик × 12 отведений
  по сырому сигналу (мВ) + ЧСС/RR/PR/QRS/QT/QTc через neurokit2 по отведению II; LightGBM
  one-vs-rest на CPU, ранняя остановка по AUROC на val (фолд 9). NaN не заполняются
  (LightGBM их понимает). Интервалы при 100 Гц грубые и смещены (медиана QRS ~160 мс) —
  использовать как относительные признаки, не как клинические значения.
- Результат бейзлайна на val: macro AUROC 0.894 (только статистики: 0.884). Метрика слегка
  оптимистична из-за early stopping по val; test не использовался.
- Нейросети (src/models.py, src/train.py, configs/{cnn1d,resnet1d}.yaml): модели отдают логиты,
  sigmoid снаружи; лосс BCEWithLogitsLoss, AdamW (без decay для bias/BN), разогрев 1 эпоха +
  косинусный спад lr, AMP float16 + GradScaler, early stopping по val macro AUROC (фолд 9).
  Выходной bias инициализируется logit(доли класса в train).
- pos_weight по умолчанию выключен (pos_weight: false): дисбаланс умеренный (HYP ~12% — самый редкий),
  а веса положительных завышают вероятности и портят калибровку, которая есть в списке метрик.
  Это отход от идеи в handoff — включается одной строкой в конфиге.
- Батч 128: замер памяти (--probe-batch) показал пик 0.26 ГБ (ResNet1d) из 4 ГБ, память не ограничивает;
  gradient accumulation поддерживается (grad_accum_steps), но не нужен.
- Аугментации (src/augment.py, секция `augment` в конфиге): сдвиг по времени ±0.5 с, масштаб амплитуды
  ×U(0.8, 1.2), дрейф изолинии (синус 0.05–0.5 Гц, до 0.3 std), гауссов шум (0.05 std), каждая с p=0.5.
  Только train, после z-нормализации (единицы — std отведения), на GPU, свой генератор случайных чисел:
  при `enabled: false` обучение бит-в-бит такое же, как без модуля. Сравнение «с/без» — configs/*_aug.yaml
  против configs/*.yaml; различаются только `experiment_name` и `augment.enabled`.
